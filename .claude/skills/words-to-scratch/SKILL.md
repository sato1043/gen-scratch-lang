言葉から Scratch のプログラムを作る
===================================

言葉で述べた処理を、日本語ブロック記法へ落として Scratch のプログラムにする。
このリポジトリが何を導出する物かは [README](../../../README.md) が述べる。

**規則はここに書かない。** 記法の書き方・値の型・ブロックの綴り・申告の意味・作品定義の
キーは、すべて知識層のページが持つ。同じ規則を 2 か所に置くと、一方だけが古びる。
このスキルが持つのは、どこを開くかと、どう実行するかだけである。

既存の .sb3 を読み解く向き（`read`）はこのスキルの対象外である。


## 読む順

1. [言葉から記法を組む手順](../../../docs/knowledge/howto.md) を通しで読む。手順・
   値の型・自己検査項目・止まったときの読み方は、すべてこのページにある
2. 迷いの種類で見るものを選ぶ

| 迷い | 見るもの |
|---|---|
| どのブロックを使うか。綴りと引数の型 | [ブロック解説](../../../docs/knowledge/blocks/README.md) |
| 作品のディレクトリに何を置くか。変数・リスト・スプライトの宣言 | [作品定義の仕様](../../../docs/knowledge/project-definition.md) |
| 日常語をどうブロックの組にするか | [イディオム集](../../../docs/knowledge/idioms/README.md) |
| 生成が止まった。申告の意味 | 手順書の[「詰まったときに見るもの」](../../../docs/knowledge/howto.md#詰まったときに見るもの) |

リンクはこのファイルからの相対で書いてある。


## 実行

図を出す。

```zsh
node src/cli.ts render <記法ファイル> --format png
```

.sb3 を組む。

```zsh
node src/cli.ts build projects/<作品名>
```

どちらもリポジトリの根を作業ディレクトリに取る。成否の見方は手順書の
[「生成して検査に掛ける」](../../../docs/knowledge/howto.md#6-生成して検査に掛ける)、
止まったときの戻り方は
[「詰まったときに見るもの」](../../../docs/knowledge/howto.md#詰まったときに見るもの)。

依存が入っていない・Node の版が合わないときは、そもそも起動しない。これは記法の誤りでは
ないので、README の[「動かせる環境」](../../../README.md#動かせる環境)と
[「開発」](../../../README.md#開発)を見る。
