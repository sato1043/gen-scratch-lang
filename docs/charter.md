gen-scratch-lang プロジェクト憲章
==================================

言葉で書いた処理を Scratch のプログラムへ変換する、解析・生成環境をつくる。


## 目的

Scratch の GUI 操作に不慣れでも、言葉で書けば Scratch のプログラムが
手に入る状態をつくる。Scratch はブロックのドラッグ&ドロップしか
入力経路を持たず、頭にある処理を形にする速度が操作に律速される。
言葉を入力に変えることでこの律速を外す。


## 提供価値

| 受け取るもの | 用途 |
|---|---|
| 日本語ブロック記法（テキスト）| 読む・直す・git で差分を追う |
| ブロック図（SVG / PNG）| 説明する・子どもと画面で読む |
| Scratch プロジェクト（.sb3）| Scratch エディタで開いて動かす |

3 つは同じ 1 つの記法から導出する。導出元が 1 つなので互いに食い違わない。

逆の向きも持つ。手元の .sb3 を渡すと、ターゲットごとの記法・ブロック図・構造の
要約・組み立て直せる作品定義を受け取れる。子どもの作品や共有された作品を、
読む・比べる・差分で追える形に落とす。


## 対象ユーザー

- **一次**: 本プロジェクトの所有者。処理を言葉と設計で表せるが、
  Scratch の GUI 操作には不慣れ
- **二次**: 生成物を読み、動かす子ども。日本語のブロック表示を前提とする


## 成功の判定

- 言葉で述べた処理が、ブロック記法として出てくる
- その記法が図になり、読んで意味が取れる
- その記法が .sb3 になり、Scratch エディタで開いて意図どおり動く
- 生成物の正しさが、人手の目視でなく機械の検査で確かめられる
- 手元の .sb3 が記法と図に落ち、読んで中身の見当が付く


## 非目標

- Scratch エディタ（GUI）の代替を作らない
- Scratch の実行エンジン（VM）を自作しない
- 既存 .sb3 を読み解く逆方向の解析を主目的にしない
- 拡張機能ブロックはペンだけを扱う。他（音楽・micro:bit・EV3・LEGO・音声合成・
  翻訳等）は扱わない
- 画像・音声素材そのものを作らない


## 制約と前提

- 対象は Scratch 3.0。ブロックラベルは日本語表示を正とする
- 実装言語は JavaScript（Node.js）。記法の解析・描画を担う
  scratchblocks が JavaScript 実装であるため
- Scratch エディタでの最終確認は自動化できない。人手の確認項目として残す


## 用語

| 語 | 意味 |
|---|---|
| 記法 | scratchblocks 記法。ブロックをテキストで表す書き方 |
| 台帳 | ブロックの対応表。日本語ラベル・記法・opcode・引数を結ぶ |
| opcode | Scratch がブロックを識別する内部名（例: `motion_movesteps`）|
| .sb3 | Scratch 3.0 のプロジェクトファイル。実体は zip |
| イディオム | 日常語で言う処理と、それを実現するブロック構成の組 |
