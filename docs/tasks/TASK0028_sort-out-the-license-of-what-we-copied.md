写した値のライセンスを整理する
==============================

## 目的

AGPL-3.0-only の上流から写した値が、MIT を宣言する公開リポジトリの追跡下にある状態を
整理する。

TASK0024 の CP6（攻撃者視点でなくセキュリティの観点）が指摘し、一次情報で確かめた。
**既存の裁定はこの形を評価していない。**

## 目的の外にある事実

2026-09-03 時点の事実。いずれも一次情報で確認した。

| 事実 | 値 | 出典 |
|---|---|---|
| scratch-vm のライセンス | AGPL-3.0-only | scratch-vm の `package.json` |
| scratch-l10n のライセンス | AGPL-3.0-only | 同上（CP6 のセキュリティ観点が取得）|
| このリポジトリの宣言 | MIT | `package.json` |
| npm への公開 | していない | `package.json` の `private: true` |
| **GitHub の可視性** | **PUBLIC** | `gh repo view` |
| 写した表の数 | 4 件（TASK0024 で 1 → 4 へ増えた）| `catalog/provenance.ts` |

既存の裁定（2026-08-18・TASK0004）は「AGPL の**依存**（`scratch-parser`）を抱える」形に
対する受容で、根拠は「`private: true` で公開せず、提供するのは生成物である」だった。
**「ソースから値を写して追跡下へ置き、そのリポジトリを公開する」形は weigh していない。**

`private: true` は npm パッケージとしての非公開であって、ソースコードの非公開ではない。

## 目標

（planning の途中。以下は候補）

- 写した値の範囲と、それぞれの著作物性の線を整理する
- ライセンスの宣言と実態を揃える

## 非目標

- 法的な助言を作らない。事実を揃えて判断の材料にするところまでを扱う
- pen の機能そのものを取り下げることは、この作業の既定の選択肢にしない
  （選択肢としては残るが、目的は整理であって撤退ではない）

## 問題

- **写した値の著作物性の線が引けない。** opcode の綴りや引数名のような事実の羅列と、
  構造を持つ表とでは扱いが違いうる。ここは法的な判断を含む
- 取りうる道が複数ある。写しをやめて依存を足す／導出へ格上げする／ライセンスの宣言を
  変える／リポジトリを非公開にする、のいずれも別の代償を持つ
- **不可逆である。** 公開済みの git 履歴からは消えない（`irreversible: high` を立てた
  理由）
