記法からブロック図
==================

## 概要

日本語のブロック記法を書いたファイルから、ブロック図を SVG または PNG で得る。
記法は人が読み書きでき、差分が git で追える。図は説明のため、あるいは子どもと画面で
読むために使う。

## 外部仕様(what)

- 日本語のブロック記法を書いたファイルを渡すと、ブロック図を SVG または PNG で
  出力する
- 出力形式は `--format` で指定する。省略すると出力先の拡張子から決め、それも無ければ
  SVG になる
- 拡大率を `--scale` で指定できる。上限は 16 倍で、超えたら止まる
- 記法として解釈できない行があれば、その行を示して終了コード 1 で停止する
- ブロックが 1 つも無い入力は成功にしない（寸法 0 の図を黙って書き出さない）
- `--help` を付けられる。使い方は標準出力へ出て、終了コード 0 で終わる
- 空の値を渡した旗（`--out ""` 等）は既定へ倒れず、どの旗が空かを述べて止まる
- 使い方の記述に無い旗は受け取らず、綴りを確かめる旨を添える

## 内部設計(how)

- scratchblocks の解析器で中間表現（Document）を得て、描画器で SVG を生成する。
  中間表現は図と .sb3 の双方の導出元になる
- Node.js 上での描画には DOM とテキスト計測が要るため `jsdom` と `canvas` を用いる
- PNG は SVG から変換する。拡大率は SVG 側だけに持たせる（両方に掛けると寸法が
  二乗になる）
- SVG は単体で表示できる形にする（配色をページ側の CSS に頼らない）
- 認識できない記述は握りつぶされず、カテゴリ `obsolete` のブロックとして中間表現に
  残る。これを拾って未知の記述を機械で検出する
- 行番号は、ブロックの綴りを元の入力から探して引く。行全体の一致を先に全行試してから
  部分一致へ落とす（順序を混ぜると短い記述が手前の正しい行に当たる）
- 図にしてよいかの判定（ブロックが 1 つも無い・認識できない記述がある）は 1 か所が
  持ち、読み取りの描画経路も同じものを通る。止めるか 1 本落とすかだけを呼ぶ側が決める
- 旗の共通の扱い（使い方の求め・空の値・使い方に無い旗）は 1 か所が持ち、4 つの
  コマンドが同じものを通る。写すと揃うのは書いた時点だけで、片方だけ直すと黙って割れる
- 拡大率の上限は実測から導く。同じ記法を倍率を変えて描き、描画の費用が起動の費用に
  埋もれる上端へ線を置く

## 制約・既知の課題

- 図の字形は環境のフォントに依存する。フォントが欠けても警告は出ない
- 英語ラベルでの入出力は扱わない
