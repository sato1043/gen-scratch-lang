演算（operators）
=================

値を計算して返すブロックの集まり。四則・比較・論理・文字列・乱数を扱う。

- 値の形（丸い）と真偽の形（尖った）がある。真偽は条件にしか差せない
- 比較（`<`・`=`・`>`）は数どうしなら数として、そうでなければ文字として比べる。
  「以上」「以下」は無いので、境界を 1 つずらすか `または` で組み合わせる
- `%1 から %2 までの乱数` は両端を含む。両方が整数なら整数を返す
- `%1 と %2`（文字を繋ぐ）は数も文字として繋ぐ。`1` と `2` を繋ぐと `12` になる
- 文字の位置は 1 から数える
- `%1 の長さ` と `%1 に %2 が含まれる` はリストのカテゴリと日本語ラベルが同じ
  である。どちらも引数の形で見分けが付く ── 選択肢（`[もちもの v]`）ならリスト、
  値（`[こんにちは]`）なら文字である。詳しくは [覆わない範囲](README.md) を参照
- `%2 の %1`（数学の関数）は調べるの `%2 の %1`（属性の取得）と日本語ラベルが同じ
  である。「の」の前が値ならこちら、選択肢なら調べるの側になる
