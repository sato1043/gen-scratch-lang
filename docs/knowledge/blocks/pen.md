ペン（pen）
===========

線を引くブロックの集まり。スプライトが動いた跡を舞台へ描く。

- ペンは拡張機能である。core の 9 カテゴリの外にあり、使った作品の .sb3 は
  ペンを使うことを申告する。Scratch エディタで開くとペンのカテゴリが出る
- 線はスプライトの x 座標・y 座標から引かれる。絵の見た目の中心ではなく座標そのもの
  である（scratch-vm 5.0.300 の `_onTargetMoved` が `target.x` / `target.y` を
  そのまま渡す）
- ペンを下ろしているか・色・太さは、スプライトごとに持つ。1 つのスプライトで
  変えても他のスプライトには及ばない
- `全部消す` だけは作品全体に効く。ペンの層は 1 枚しかなく、どのスプライトの跡も
  まとめて消える
- 色の決め方が 2 通りある。色そのものを渡す `ペンの色を %1 にする` と、色・鮮やかさ・
  明るさ・透明度を 0 から 100 の数で決める `ペンの %1 を %2 にする` である
- `スタンプ` はスプライトの今の見た目を、その場へ写す。写したものは線と同じ層に載る
  ので `全部消す` で消える
- Scratch 3 のパレットに出ない旧ブロックが 4 件ある（濃さと色相を数で決めるもの）。
  **うち 3 件は台帳が扱わない。** 残る 1 件は `ペンの色を%1にする` の綴りを現行の
  ブロックと分け合っており、解析器がそちらを選ぶ。そこで台帳はこの綴りを現行の
  ブロック（色を直に決めるもの）へ繋いである ── 記法に `ペンの色を [#ff8c1a] にする`
  と書くと、色を直に決める側になる。詳しくは [覆わない範囲](README.md) を参照
- 色を変えても、線を引かなければ画面は変わらない。`スタンプ` で写したものは
  スプライトの真下に重なるので、動かさないと写ったことが見えない
