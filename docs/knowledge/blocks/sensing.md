調べる（sensing）
=================

外の様子を読み取るブロックの集まり。触れたか・押されたか・どこにあるか・
何秒経ったかを返す。

- 真偽の形（`%1 に触れた` 等）は `もし〜なら` や `〜まで待つ` の条件に差す。
  単独では置けない
- 触れた判定は絵の見えている部分どうしで決まる。隠れているスプライトは触れない
- `%1 と聞いて待つ` は入力欄を出し、書き込まれるまで止まる。結果は `答え` に
  入り、次に尋ねると上書きされる
- タイマーは作品全体で 1 つである。2 か所でリセットすると互いに影響する
- `%2 の %1` は他のスプライトやステージの値を読む。**`[対象 v] の [属性 v]` の順**で、
  英語の `x position of Sprite1` とは逆になる。演算の `%2 の %1`（絶対値や平方根）と
  日本語ラベルが同じで、「の」の前が選択肢ならこちら、値なら演算側になる。ただし
  こちらは台帳が引数を解けないため、記法から .sb3 にはできない
    - 対象の名が数学の関数と同じ作品（`([sin v] の [x座標 v])`）は、解析器が演算の側を
      選ぶので書けない
- 逆に `音量`（マイクの大きさ）は音のカテゴリの `音量` と同じラベルである。双方とも
  引数を持たないので、`(音量 :: sensing)` とカテゴリを明示した側だけがこちらになる。
  明示しなければ音の側が呼ばれる。詳しくは [覆わない範囲](README.md) を参照
