制御（control）
===============

処理の流れを決めるブロックの集まり。待つ・繰り返す・条件で分ける・クローンを
扱う。

- 中身を持つブロック（`ずっと`・`%1 回繰り返す`・`もし %1 なら`）は、記法では
  `end` で閉じる。閉じ忘れると後ろのブロックが中身に吸い込まれる
- `もし %1 なら` は、`でなければ` を書くかどうかで Scratch では別のブロックに
  なる。記法では中身の数から生成器が選ぶので、書き分けを気にしなくてよい
- `ずっと` の後ろにはブロックを繋げない。繰り返しから抜けないためである
- `%1 秒待つ` は時間で待ち、`%1 まで待つ` は条件が満たされるまで待つ。他の
  スプライトの動きを待ち合わせるときは後者を使う
- クローンは実行時に複製を作る。`クローンされたとき` が複製側の起点になる
