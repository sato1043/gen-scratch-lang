言葉から記法を組む手順
======================

やりたい処理を日常語で述べた状態から、生成に掛けられる記法へ落とすまでの手順を
書く。手順のあとに自己検査項目を置く。書き終えたら自己検査項目を上から確かめる。

例として「旗を押したら、ネコがマウスを追いかけて、触れたら点が増える」を使う。


## 手順

### 1. 処理を短い文へ割る

1 文に 1 つの動作だけを残す。「〜して、〜する」は割る。時間の前後と、条件が
付くかどうかが見える形にする。

- 旗を押したときに始まる
- ずっと繰り返す
- マウスのほうを向く
- 少し進む
- もしマウスに触れたら、点を 1 増やす

### 2. 起点を決める

いちばん上に置く帽子を選ぶ。起点は [イベント](blocks/events.md) のカテゴリに
ある。「旗を押したとき」「キーを押したとき」「合図を受け取ったとき」のどれかに
当たることが多い。

1 つのスクリプトに帽子は 1 つしか付かない。起点が 2 つあるなら、スクリプトを
2 本に分けて空行で区切る。

逆に、空行はスクリプトを割る。1 本の途中に読みやすさのつもりで空行を置くと、
そこから下は帽子を持たないスクリプトになり、旗を押しても走らない。**生成は
成功し、検証も通る**。区切りたいときだけ空行を置く。

### 3. 文をブロックへ置き換える

割った文を上から順にブロックにする。どのカテゴリを見ればよいかは、文の動詞で
見当が付く。

| 文の言い方 | 見るカテゴリ |
|---|---|
| 動く・向く・座標 | [動き](blocks/motion.md) |
| 言う・見せる・隠す・大きさ | [見た目](blocks/looks.md) |
| 鳴らす | [音](blocks/sound.md) |
| 〜したとき・合図 | [イベント](blocks/events.md) |
| 繰り返す・待つ・もし | [制御](blocks/control.md) |
| 触れた・押された・時間 | [調べる](blocks/sensing.md) |
| 足す・比べる・つなぐ・乱数 | [演算](blocks/operators.md) |
| 覚える・数える | [変数](blocks/variables.md) |
| 並べる・記録する | [リスト](blocks/list.md) |
| 線を引く・跡を残す | [ペン](blocks/pen.md) |

繰り返しと条件は中身を持つ。記法では中身を字下げし、`end` で閉じる。

```scratchblocks
緑の旗が押されたとき
ずっと
  [マウスのポインター v] へ向ける
  (3) 歩動かす
  もし <[マウスのポインター v] に触れた> なら
    [スコア v] を (1) ずつ変える
  end
end
```

### 4. 値と入れ子を埋める

値の置き場には 6 つの型がある。型が合っていないと、生成が止まるか、意図と違う
場所へ値が入る。ブロックごとにどの引数がどの型を取るかは、[ブロック解説](blocks/README.md)
の各ページの一覧に載っている。

| 型 | 書き方 | 入るもの |
|---|---|---|
| 数 | `(10)` | 数、または値を返すブロック |
| 文字 | `[こんにちは]` | 文字、または値を返すブロック |
| 選択肢 | `[マウスのポインター v]` | 決められた候補、または名前 |
| 名前 | `[スコア v]` | 作品の中で付けた名前（リスト・変数・合図・音・コスチューム）|
| 条件 | `<...>` | 真偽を返すブロックだけ。値は書けない |
| 色 | `[#ff0000]` | `#` に続く 16 進 3 桁か 6 桁 |

向きとリストの位置の欄は数で書く。選択肢の見た目（`[右 v]`）でも素の文字（`[右]`）でも
解析は通るが、中身は数として扱われるので `右` という文字がそのまま入る。2026-08-19 から、
数として読めない値は止まる。一覧ではこの欄の型に `※` が付く。

値を返すブロックは、値の置き場へそのまま入れ子にできる。

```scratchblocks
((1) から (10) までの乱数) 歩動かす
```

置き場と書き方が食い違うと、生成はその行を示して止まる（2026-08-18 から）。
それまで通っていた次の形は止まるので、書き直す。

| これまで通っていた形 | これから |
|---|---|
| `[はじめ] を送る` | `[はじめ v] を送る` |
| `[マウスのポインター] へ向ける` | `[マウスのポインター v] へ向ける` |
| `[スペース] キーが押されたとき` | `[スペース v] キーが押されたとき` |
| `[こんにちは v] と言う` | `[こんにちは] と言う` |

向きとリストの位置の欄は、2026-08-19 から数でないと止まる。書き方（`[... v]` か
`[...]` か）ではなく、書いた値が数として読めるかを見る。

| これまで通っていた形 | これから |
|---|---|
| `[右 v] 度に向ける` | `(90) 度に向ける` |
| `[記録 v] の [最後 v] 番目` | `[記録 v] の (1) 番目`（番号で書く）|

`最後`・`すべて`・`どれか` に当たる書き方は Scratch 3 に無い。番号で指す。

止まったときに `v` を外して通ったなら、別のブロックになっていないかを疑う。
同じ日本語の綴りを持つブロックがあり、`v` の有無で別のブロックとして読まれる
ことがある（[覆わない範囲](blocks/README.md) の綴りの衝突）。

### 5. 変数とリストを宣言する

変数とリストは記法だけでは作れない。作品の定義（`project.yaml`）に名前と初期値を
書く。宣言の無い名前を記法に書くと、生成はその行を示して止まる。定義に書けるキーの
一覧と既定値は [作品定義の仕様](project-definition.md) にある。

合図（メッセージ）の名前は記法から集めるので、定義に書かない。

```yaml
スプライト:
  - 名前: ネコ
    スクリプト: neko.sbk
    変数:
      スコア: 0
```

### 6. 生成して検査に掛ける

作品のディレクトリを渡して .sb3 を作る。終了コードが 0 でなければ、示された行を
直してからやり直す。

組み上がったものは Scratch 公式の検証器へ通してから書き出す。通らなければ書き出さない
ので、半分だけできた .sb3 は残らない。ただし前に成功したときの出力はそのまま残る。
成否はファイルの有無でなく終了コードで見る。

この失敗には行番号が出ない。記法の綴りでなく、組み上がったあとの構造を見るためである。

```zsh
node src/cli.ts build projects/<作品名>
```

読んで確かめたいときは、同じ記法から図も出せる。

```zsh
node src/cli.ts render projects/<作品名>/neko.sbk --format png
```


## 自己検査項目

書き終えたら、上から順に確かめる。

- [ ] スクリプトごとに帽子が 1 つある。2 つ以上並べていない
- [ ] 中身を持つブロック（`ずっと`・`%1 回繰り返す`・`もし %1 なら`）が
      すべて `end` で閉じている
- [ ] 条件の置き場（`<>`）に入れたのは真偽を返すブロックである。数や文字を
      書いていない
- [ ] 値の置き場と書き方が合っている。数は `(10)`、文字は `[こんにちは]`、
      選択肢は `[マウスのポインター v]` で書いている
- [ ] ドロップダウンの綴りが選択肢どおりである。思いつきの言葉を書いていない
      （綴りは [ブロック解説](blocks/README.md) の各ページの一覧にある）
- [ ] 使った変数とリストを作品の定義で宣言した
- [ ] 合図の名前は、送る側と受け取る側で同じ綴りである
- [ ] 生成が終了コード 0 で終わる
- [ ] 図に起こして、読んで意味が取れる
- [ ] Scratch エディタで開き、意図どおり動く（自動では確かめられない）


## 詰まったときに見るもの

### 止まったとき

生成が止まると、何が起きたかを申告して終わる。申告の左端がその名前である。

| 申告 | 何が起きたか | 見るもの |
|---|---|---|
| `台帳に無いブロック` | 記法の綴りが台帳に無い | [覆わない範囲](blocks/README.md)。拡張機能はペンだけを扱う |
| `台帳が引数を解けないブロック` | 台帳に載ってはいるが、引数を組み立てる経路が無い | [覆わない範囲](blocks/README.md) の「引数名を取れないブロック」 |
| `ブロック定義の形が読めない` | `定義` の書き方が崩れている。作るブロックの見出しや引数の名前を読めない | [ブロック定義](blocks/custom.md) |
| `真偽の引数は扱えない` | ブロック定義の引数を `<>` で書いた | [ブロック定義](blocks/custom.md)。引数は `()` か `[]` で書く |
| `同じ綴りのブロック定義が 2 つある` | 綴りの同じ `定義` を 2 つ書いた | 呼び出しがどちらに結び付くか決められない。綴りを分ける |
| `ブロック定義の引数に名前が無い` | `定義 えがく ()` のように括弧を空で書いた | 名前が無いと本体から参照できない。括弧の中に名前を書く |
| `定義がスクリプトの途中にある` | `定義` の前の行にブロックが続いている | `定義` は帽子なのでそこでスクリプトが割れる。1 行空ける |
| `再描画しないブロックの書き方が違う` | 作品定義の `再描画しないブロック` が並びでない、または要素が文字列でない | [作品定義の仕様](project-definition.md) |
| `再描画しないブロックの名前が記法に無い` | 挙げた名前と記法の定義の綴りが違う | 申告が記法の定義を並べる。[ブロック定義](blocks/custom.md) |
| `選択肢に無いラベル` | ドロップダウンの綴りが選択肢に無い | 申告が書ける候補を並べる。一覧は[ブロック解説](blocks/README.md)の各ページ |
| `引数の書き方が台帳と噛み合わない` | 値の置き場と書き方が食い違う | 上の「値と入れ子を埋める」 |
| `影を持たない入力に値を書けない` | 条件の置き場（`<>`）に数や文字を書いた | 同上 |
| `変数が宣言されていない` / `リストが宣言されていない` | 作品の定義に無い名前を使った | [作品定義の仕様](project-definition.md) |
| `公式検証器が弾いた` | 組み上がった .sb3 を Scratch の検証器が拒んだ | 行番号は出ない。直前に足した記法から疑う |
| `印が指せない符号位置を書いている` | 印（`⟪U+000A⟫`）に、文字として存在しない番号を書いた | 下の「書けない文字を印で書く」 |

### 書けない文字を印で書く

改行やタブのように記法へそのまま書けない文字は、印で表す。`⟪U+000A⟫` が改行、
`⟪U+0009⟫` がタブである。番号は Unicode の符号位置を 16 進の大文字で書き、4 桁に
満たなければ 0 を足す。

読み取り（`read`）が書き出す記法にもこの形で入る。`build` は印を元の文字へ戻すので、
書き出したものをそのまま組み立て直せる。

- 印の括弧そのものを値として書きたいときは `⟪U+27EA⟫` と書く
- 文字として存在しない番号（`⟪U+110000⟫` 以上、`⟪U+D800⟫`〜`⟪U+DFFF⟫`）は
  書けない。書くと `印が指せない符号位置を書いている` で止まる
- 図（SVG / PNG）にも印のまま出る。図と .sb3 は同じ記法から導くので、図に見える綴りを
  戻したものが .sb3 に入る

### 止まらないが困ったとき

| 症状 | 見るもの |
|---|---|
| 書いたのに別のブロックになる | 同じ日本語ラベルの衝突。[覆わない範囲](blocks/README.md) |
| どう組むか思いつかない | [イディオム集](idioms/README.md) |
