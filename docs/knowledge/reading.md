既にある作品を読み解く
======================

手元の .sb3 を、読める形（記法・図・要約・作品定義）へ落とす手順と、止まったときに
見るものを書く。書く向き（言葉から記法を組む）は
[言葉から記法を組む手順](howto.md)が持つ。

## 使い方

```zsh
node src/cli.ts read <作品.sb3>
```

書き出し先は省略すると `out/<入力名>/` になり、`--out` で変えられる。図の形式は
`--format svg|png`、図の拡大率は `--scale`、記法の言語は `--locale ja|en` で指定する。
記法とその中の印だけが言語に従い、要約・作品定義・申告は日本語のままである。

## 書き出すもの

| ファイル | 中身 |
|---|---|
| `<ターゲット名>.sbk` | ステージ・スプライトごとの日本語ブロック記法 |
| `<ターゲット名>-<n>.svg` / `.png` | スクリプトごとのブロック図 |
| `summary.md` | 構造の要約。読めなかったもの・落としたものの断りもここに載る |
| `project.yaml` | 組み立て直せる作品定義。[作品定義の仕様](project-definition.md)の形 |
| `<32 桁の 16 進>.<拡張子>` | コスチュームと音の実体。作品定義がこの名前で指す |

記法にできないブロックは印を付けて残り、黙って落ちない。書き出したものを作品の
ディレクトリに揃えれば、`build` で .sb3 を組み立て直せる。

**素材の名前は .sb3 の中の名前（中身の md5 + 拡張子）をそのまま使う。** 対応が自明に
なり、他人が決めた綴りがファイル名に現れない。人が読む呼び名は作品定義の `名前` にある。

素材を落とすことがある。落とせば件数を申告し、**終了コードは 0 にならない**。落ちるのは
次の 3 つで、いずれも作品定義からも外すので、定義が実在しないファイルを指すことはない。

- .sb3 の中にその素材が入っていない（公式検証器は素材の欠落を通すので、この形は実在する）
- 名前が md5 と拡張子の形をしていない
- 拡張子が Scratch の扱う形式でない
  （png / svg / jpeg / jpg / bmp / gif / wav / wave / mp3）

## 止まったとき

読み取りが止まると、何が起きたかを申告して終わる。申告の左端がその名前である。

| 申告 | 何が起きたか | 見るもの |
|---|---|---|
| `読み取れない .sb3` | zip として開けないなど、.sb3 の形をしていない | 渡したものが Scratch 3 の .sb3 か確かめる。壊れているなら Scratch エディタから書き出し直す |
| `読み取れる形をしていない` | 中身の形が Scratch 3 と違う | 申告の手当てに従う。Scratch 2 の作品なら Scratch 3 で開いて保存し直すと読める |
| `公式検証器が弾いた` | Scratch 公式の検証器が作品を拒んだ | 下の「逃げ道（--anyway）」 |
| `素材を取り出せない` | 素材が壊れているか、展開後の総量が上限を超えた | 記法・図・要約は書けている。素材だけが揃わない |
| `素材が .sb3 に入っていない` | project.json が名乗る素材が中に無い | 元の .sb3 が壊れている。Scratch エディタから書き出し直す |
| `素材の名前が形を満たさない` | 名前が md5 と拡張子の形でない | その素材は落ちる。ほかは書けている |

量の上限（図の本数・書き出す量・拡大率）で止まったときは、切り詰めずに全体を
止めている。黙って一部だけ書くと、読めた範囲が全部に見えるためである。

## 逃げ道（--anyway）

Scratch 公式の検証器が弾いた作品を、それでも読みたいときに `--anyway` を付ける。
実装と成果物はこの経路を「逃げ道」と呼ぶ ── `summary.md` の見出し
「逃げ道を通して読んだ」と、図（SVG）の先頭の断りに、この語で現れる。

- 検証は飛ばさない。弾いた理由と、そのとき保証しないことを申告して読み進む
- 旗の名は「とにかく読む」の意で、降ろす対象（検証器の判定）を名に含まない。
  受け入れ検査（zip のエントリ数・project.json の大きさなどの資源の上限）は、
  旗があっても掛かる
- 保証しないこと（Scratch エディタで開けるか・組み立て直せるか・記法が実物と
  一致するか）は `summary.md` の断りから読める
