イディオム集
============

日常語で言う処理と、それを実現するブロック構成の組を並べる。「こう言いたい」から
「こう書く」への辞書として引く。

各項目の記法はそのまま生成の入力になり、自動テストが解析と往復検査へ通す。ここに
書いた記法が Scratch のブロックとして成立しなくなれば、テストが落ちる。

| ページ | 中身 |
|---|---|
| [基本](basics.md) | 動き続ける・キーで操る・数える・偶然を使う |
| [データ](data.md) | 値を覚える・並べる・比べる |
| [やりとり](interaction.md) | 合図・追いかける・押されたら反応する |
| [見た目と音](looks-and-sound.md) | 見え方と音を変える |
| [線を引く](drawing.md) | ペンで描く・色を変える・姿を写す |

組み方の手順そのものは [言葉から記法を組む手順](../howto.md) にある。ブロック 1 つ 1 つの
一覧は [ブロック解説](../blocks/README.md) にある。
